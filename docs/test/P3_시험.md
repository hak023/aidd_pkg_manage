## 3. 실제 Gemini 결과 요약 (TC-P3-R1, R2)

- **모델:** `gemini-3.5-flash-lite`. `GEMINI_MODEL`이 비어 있어 자동으로 골랐습니다.
- **L1:** 7.5초
  - 상태: 충분 8 / 부족 4 / 확인 안 됨 0
  - 관련자 4명, 상충 1건, 질문 5개
  - 질문은 병행 기간 확정, 비상 로그인, IdP 협의, 보안 심의, 세부 마일스톤에 관한 것으로 모두 적절했습니다.
- **L2:** 4.9초, 3,032자
  - 12개 장 + 변경 이력, FR 5개, NFR 2개
  - 우선순위·수용 기준은 자료에 없어 "확인 필요"로 남겼습니다(G-02 준수).
  - 출처 표기를 유지했고, 담당자 입력은 `[담당자 보완 2026-11-21]`로 표기했습니다.
- **관찰:** 시험에서 질문 1번 칸에 질문 2번의 답을 넣었습니다. 모델은 이를 그대로 섞지 않고, 미결 사항에 "명시적 답변으로 보기 어려움"이라고 남겼습니다. 바람직한 동작입니다.
