## 1. TC 목록

### A. 자동 단위

| ID | 내용 | 기대 결과 |
|---|---|---|
| TC-P6-01 | 공개 지시문과 실제 프롬프트 비교 (2~5단계) | 공개 지시문의 자리 표시에 자료를 넣으면 `buildReviewPrompt`, `buildPrdPrompt`, `buildDocReviewPrompt`의 결과와 글자까지 같음 |
| TC-P6-02 | Gemini 요청 내용 비교 | L1·L2·L4 요청의 시스템 지시문, temperature, 응답 스키마가 공개 내용과 같음. L2는 응답 스키마 없음. L5의 시스템 지시문은 L4와 같음 |

## 4. 참고

- 프롬프트 조립 코드(`buildPrdPrompt`)를 나누었지만 조립 결과는 바뀌지 않았습니다. TC-P6-01과 기존 TC-P3·TC-P4 시험이 함께 통과합니다. 이 변경 뒤에 실제 Gemini로 PRD·검토를 다시 실행하지는 않았습니다.
