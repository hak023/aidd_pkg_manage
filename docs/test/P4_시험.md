- **L4 Architecture 세부**
  - 부분 2건:
    - NFR-01 "PRD 3초 vs 설계서 2초"
    - NFR-02 "PRD 1년 vs 설계서 180일"
  - PRD에 없는 내용: "기존 계정 일괄 전환(병행 없음)"
  - 질문: 두 값의 차이 사유
- **L5 QA 세부:**
  - FR-01~04는 TC-01~04에 대응했습니다.
  - 비기능 시험 누락과 예외 시나리오 보강을 지적했습니다.
- **교훈:** flash-lite 계열은 프롬프트 지시보다 **입력 구성과 응답 스키마 제약**에 더 잘 따릅니다.

  - 식별자는 enum으로 묶습니다.
