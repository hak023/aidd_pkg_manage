## 1. 요청 내용

- git push는 나중에 직접 하겠으니 실행할 수 있는 ps1 스크립트로 남겨 달라.
- `.env.local`에 값을 입력해야 하는지, 필수 입력값은 무엇인지 알려 달라.

## 2. 수행 내용

### `scripts/git-push.ps1` 작성

동작 순서는 다음과 같습니다.

1. 커밋하지 않은 변경을 보여 줍니다. `-Message`를 주면 함께 커밋합니다.
   - 변경 목록에 `.env` 파일이 있으면 커밋하지 않고 중단합니다.
2. `-ResetCredential`을 주면 저장된 GitHub 로그인 정보를 지웁니다.
3. 올릴 커밋 목록을 보여 주고 `origin main`으로 push합니다.
4. push가 실패하면 원인에 맞는 해결 방법을 안내합니다.
   - 403(권한 없음)
   - 원격에 로컬에 없는 커밋이 있는 경우

PowerShell 7과 Windows PowerShell 5.1 모두에서 한글이 깨지지 않도록 UTF-8(BOM)으로 저장했습니다. 구문 검사만 했고, 스크립트를 실행하지는 않았습니다.

### 환경 변수 필수값 정리

환경 변수 필수값은 사용자에게 안내했습니다. 내용은 `docs/guides/메일-연동-가이드.md` 3·4장과 같습니다.

## 4. 결정 사항 / 미결 사항

- **결정:** git push는 사용자가 나중에 스크립트로 직접 실행합니다.
- **미결:** 사용자가 `web/.env.local`에 Gmail 값 3개를 입력합니다. 이후 개발 서버를 다시 시작하고 실제 송수신을 확인합니다.
