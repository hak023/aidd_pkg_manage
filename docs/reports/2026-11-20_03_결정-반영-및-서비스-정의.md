## 1. 요청 내용

**결정 사항**
- D-01 실무 사이트
- D-02 시나리오 전체 시연 (시뮬레이터로 자체 검증)
- D-03 1인 사용 + config 기반 더미 로그인
- D-04 Gemini API (저가 등급)
- D-05 공인 사이트 무료 배포
- D-06 시연 예시 "통화매니저 SSO 로그인 기능 개발"
- D-07 PRD 양식 설계 필요

**시나리오 (사용자 제시)**
1. 단위서비스 > 라벨링 > 개발사항 트리 (N개, 드래그 이동)
2. 개발사항별 가로 progress 그래프
3. 수집 요청 메일을 회사 메일로 발송 → 회사 PC의 Outlook·Copilot(Work IQ)이 회신 작성 → 사용자가 회신
4. Gmail로 회신 수신 → LLM 점검 → 사용자 추가 입력 → PRD.md 생성 → 공유 메일 발송
5. 개발사의 Architecture·QA md를 Gmail로 수신 → LLM으로 확인·점검 → 리포트 편집·공유
6. 진행상황 요청·회신 → 마일스톤과 날짜 표시 → 완료

**요청:** 시나리오 정리, 수집 요청 메일 작성 방안(5번), 수집할 정보 제안(6번)
