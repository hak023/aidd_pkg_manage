## 1. 요청 내용

> docs 폴더를 만들어 기존 문서를 정리해 달라. 앞으로 docs/reports에 요청 대화별 리포트를 날짜를 포함해 체계적으로 작성해 달라. 필요하면 AGENTS.md 같은 파일로 관리하라. 시나리오, 제공 기능, 목표와 범위는 먼저 논의한 뒤 진행하고 싶으니 정리해서 제안해 달라.

## 2. 수행 내용

- 작업 폴더 최상위에 있던 HTML 6개를 `docs/ax-worksheets/`로, zip을 `docs/archive/`로 옮겼습니다.
  - 문제정의서 등이 다른 문서를 파일명으로 참조하므로 **파일명은 바꾸지 않았습니다**.
  - zip 안의 프로토타입 정의서와 시나리오 프로토타입은 현재 파일보다 오래된 버전임을 확인해 색인에 적었습니다.
- `AGENTS.md`에 작업 규칙을 정리했습니다: 프로젝트 개요, 폴더 구조, 리포트 규칙, 진행 원칙.
- Claude Code가 이 규칙을 자동으로 읽도록 `CLAUDE.md`에서 `AGENTS.md`를 불러오게 했습니다.
- 리포트 체계를 만들었습니다: 파일명 `YYYY-MM-DD_NN_주제.md`, 양식(`_TEMPLATE.md`), 색인(`reports/README.md`).
- 앞선 요청(#01 개발 계획)도 소급해서 리포트로 남겼습니다.
- 논의안을 작성했습니다: 결정 항목 D-01~D-07, 시나리오 후보 SC-01~SC-08, 기능 우선순위(MoSCoW).
