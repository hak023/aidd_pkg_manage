| 관련 문서 | `docs/ax-worksheets/` 전체 |

## 1. 요청 내용

> 기존에 작성했던 내용과 아이디어를 바탕으로 웹사이트를 만드는 것이 목적이다. 웹사이트 개발 계획을 세워 달라.

## 2. 수행 내용

- AX 실습 산출물 6종(HTML)과 zip 아카이브의 내용을 텍스트로 추출해 검토했습니다.
- 산출물의 흐름을 정리했습니다: 업무분석 → 문제정의·가설 → 구조정의 → 프로토타입 정의서 → 시나리오 프로토타입(모의 AI, 시연용).
- 웹사이트를 "시연용 프로토타입을 실제 저장과 AI 연결이 가능한 업무 도구로 올리는 것"으로 해석하고 계획 초안을 작성했습니다.

## 3. 결과물 (계획 초안 요지)

| Phase | 기간(안) | 내용 |
|---|---|---|
| 0. 사전 확인 | 1주 | 보안·허용 AI 환경(Q-01), PRD·공유자료 양식(Q-02) 확인, 합성 시드 데이터 정리 |
| 1. MVP | 2~3주 | S-01 자료 준비 → S-02 요구사항·출처 검토 → S-03 PRD·공유자료 검토/확정/내보내기. 모의 AI 어댑터 사용 |
| 2. 실제 AI 연결 | 2주 | 구조화된 출력과 원문 위치 검증(G-02), 자료 속 지시문 분리(G-04), 실패 처리(G-05) |
| 3. 확장 기능 | 2~3주 | F-02 관련 문서 재사용, F-03 Architecture·QA 대조 |
| 4. 시범 적용 | 4주 이상 | KPI K-01~K-04 측정 기능, 기존 방식과 비교 |

- 기술 스택 제안: Next.js(TypeScript), SQLite에서 PostgreSQL로 전환, `LLMAdapter` 인터페이스(모의 / 사내 LLM / 외부 API)
- 핵심 데이터 모델: Project, Source, Requirement, SourceSpan, Question, Document, AuditLog

## 4. 결정 사항 / 미결 사항

**결정**
- 없음 (초안 제시 단계)

**미결 (사용자 확인 필요)**

- AI 연결 방식 (사내 허용 LLM 여부)
- 배포 위치 (로컬 / 사내 서버 / 클라우드)
- 기술 스택 제약
