# P6 프롬프트 공개 설계

- 상태: 완료 (2026-11-25). 실제 Gemini 설정에서의 화면 확인(TC-P6-R1)은 미확인
- 기준: [작성·검토 프롬프트 공개 계획안](../proposals/2026-11-25_프롬프트-공개-계획.md) 0장 결정
- 시험: [docs/test/P6_시험.md](../test/P6_시험.md)

## 1. 범위

**포함**

1. 개발사항 상세의 **단계 설명 카드**에, 2·3·4·5단계를 선택했을 때 그 단계의 작성·검토 방식을 표시합니다.
   - 2단계 수집 내용 검토 (L1), 3단계 PRD 작성 (L2), 4단계 Architecture 검토 (L4), 5단계 QA 검토 (L5)
2. LLM에 보내는 **시스템 지시문, 작업 지시문, 응답 형식(JSON 스키마)의 원문**을 보여 줍니다.
3. 프롬프트 밖에서 시스템이 하는 처리(검증, 재시도, 머리글·리포트 작성 등)를 함께 보여 줍니다.
4. 지금 설정의 실행 방식(Gemini 모델 설정 또는 모의 LLM)을 표시합니다.

**제외**

- 실제로 보낸 프롬프트(자료가 채워진 전문)의 저장과 문서 버전별 출처 표시 (결정 4)
- "프롬프트 공개" 전용 페이지 (결정 1)
- 시연 데이터 표기 변경, 공유 메일 표기 (결정 5·6)
- L3(메일 분류), L6(진행상황 해석) 프롬프트
- 프롬프트 내용 수정

## 2. 원칙

| 원칙 | 구현 |
|---|---|
| 원문 그대로 | 지시문은 실제 호출에 쓰는 상수(`REVIEW_SYSTEM`, `PRD_SYSTEM`, `DOCREVIEW_SYSTEM`)와 조립 함수(`buildReviewPrompt`, `renderPrdPrompt`, `buildDocReviewPrompt`)에서 얻습니다. 화면용 문구를 따로 쓰지 않습니다 |
| 자료 자리만 표시 | 조립 함수에 자료 대신 `{수집 회신 본문}` 같은 자리 표시를 넣습니다. 그 밖의 글자는 실제 프롬프트와 같습니다 (TC-P6-01) |
| 설정값도 한 곳에서 | temperature는 `temperatureFor(task)`를 실제 호출과 화면이 함께 씁니다 (TC-P6-02) |
| 로그인한 사용자에게만 | 원문은 `GET /api/prompts`로만 내려 줍니다. 클라이언트 컴포넌트는 `disclosure.ts`에서 타입만 가져옵니다. 값을 가져오면 로그인 없이 받을 수 있는 정적 JS에 원문이 들어가기 때문입니다 |
| 실제와 다른 경우 표시 | 모의 LLM이면 "지금 설정에서는 아래 지시문을 보내지 않고 규칙으로 결과를 만듭니다"라고 표시합니다 |

## 3. 화면

단계 설명 카드의 "사용자가 할 일 / 시스템이 하는 일 / 완료 조건" 아래에 표시합니다 (`PromptDisclosure.tsx`).

- **기본은 한 줄로 접힘 (2026-11-25 변경):** `▶ 작성 방식 · L2 PRD 생성 · 입력 자료, 프롬프트 원문, 시스템 처리`. 누르면 아래 내용이 펼쳐집니다.
  - 내용은 처음 펼칠 때 한 번만 불러옵니다. 단계를 바꾸면 다시 접힌 상태로 시작합니다.
  - 한 줄 제목(점검 방식 / 작성 방식 / 검토 방식, 작업 이름)은 `web/src/lib/domain/disclosure.ts`에 둡니다. 프롬프트가 없어 클라이언트에서 가져와도 됩니다.
- **펼친 내용:**
  - 실행 방식 (지금 설정의 Gemini 모델 또는 모의 LLM)
  - 흐름 3칸: ① 입력 자료 → ② LLM에 보내는 지시(줄 수, 응답 형식, temperature, 모델 설정 순서) → ③ 시스템이 하는 처리
  - 참고 (※): 4·5단계가 같은 지시문을 쓴다는 점, QA 검토에 Architecture를 보내지 않는다는 점
  - 원문 (한 번 더 펼쳐서 봄): 시스템 지시문, 작업 지시문, 응답 형식(JSON 스키마). 각각 복사 버튼
- 1·6·7단계에서는 표시하지 않습니다.

## 4. API

| 메서드 · 경로 | 내용 |
|---|---|
| `GET /api/prompts?stage=review\|prd\|arch\|qa` | 해당 단계의 공개 내용. 다른 값은 400. 로그인하지 않으면 401 (`proxy.ts`) |
